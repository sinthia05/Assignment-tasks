# AssignPro – Teacher Assignment Simulator


## Project Description
AssignPro is a console-based application developed using **C++** that simulates an automated teacher-to-course assignment system for academic scheduling.  
The system assigns teachers to courses based on **faculty matching**, **availability**, and **minimum workload**, while ensuring that no teacher is assigned to overlapping time slots.  
If no suitable teacher is available for a course, the system marks it as **TBA (To Be Assigned)**.

This project is designed as part of the **CSE1290 – Software Development** course.


## Key Features
- Add and delete teachers with faculty information  
- Add and delete courses with required faculty and time slots  
- Automatic teacher assignment based on priority rules  
- Time conflict detection to avoid overlapping classes  
- Priority handling using least workload strategy  
- Search and display a teacher’s full assigned routine  
- Display complete course–teacher assignment schedule  



## Programming Language
- **C++**
- Console-based, menu-driven application
